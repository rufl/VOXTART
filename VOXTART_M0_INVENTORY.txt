VOXTART release validation
--------------------------
- Windows release gate: ``python tests/python/voxtart_e2e.py``. It enforces the 93 core, 29 native Blender, and 7 headless editor test baseline, isolates persistence preferences, bootstraps ``scripts/addons_core`` before reopening a saved blend, validates package-relative paths, runs the packaged launcher, and exercises the visible GUI.
- Direct Linux suite entrypoints enforce the same 93/29/7 collected-test contract, so accidental test loss fails before coverage or artifact upload.
- CI downloads verify pinned official Blender 5.2.2 SHA-256 digests before extraction, and the workflow token is limited to read-only repository contents.
- All reusable GitHub Actions are pinned to immutable commit revisions, and checkout steps disable credential persistence after fetching source.
- Package assembly: ``python tools/assemble_voxtart_package.py --output <directory> --runtime-source <Blender runtime>`` creates an isolated release-copy tree. The E2E smoke path adds ``--link-runtime`` to avoid copying the 1.2 GiB runtime; its manifest records ``smoke-linked`` versus ``release-copy`` explicitly.
- Current local evidence: core coverage 6466/6466 (100.000%), Blender-facing coverage 6137/13784 (44.520%), and headless performance at 32768 voxels with 509.789 ms rebuild and 59.688 ms selection in the artifact probe.
- CI evidence checks require the expected coverage, performance, baseline, GUI marker, GUI screenshot, and Windows E2E log files before upload.
- Remaining release risk: this workstation cannot execute the hosted GitHub Actions Windows/Ubuntu jobs; the workflow is checked in and the full Windows gate passes locally, but hosted-run status remains an external prerequisite before publishing.
